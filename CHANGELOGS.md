# Sep. 1 2025 to Oct. 12 2025

With the announcement of Nuclear Throne Update #100, I decided to completely refactor the entire codebase, as it was made when I was completely clueless about the process of maintaining the codebase in a usable state.
There's still a ton of work that needs to be done. In fact, anything mentioned in this list is merely just the tip of the iceberg that there is still to be worked on.
With that, I introduce you to the list of all core changes to the project and its codebase:
- Switched to the [GPL-3.0](LICENSE) license, as the previous choice of the CC BY-NC-ND license did not allow users to do what this project is intended to permit..
- Introduced a set of Build Scripts that allows for trivial resource extraction, provided that you own a legit copy of Nuclear Throne on Steam
- Fixed tons of incorrect asset naming issues and introduced a handful of lost sprites and sounds into the game
- Initial refactoring for several content systems (still pretty much WIP)
